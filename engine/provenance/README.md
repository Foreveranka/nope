# Research source archive

Byte-exact copies of the original synthetic experiment and evaluator that produced the pinned artifact profile. Files use `.py.txt` deliberately: the historical experiment has top-level execution, writes outputs, and includes a single-key auction that is NOT the private multi-owner MPC auction. The current engine never imports or executes these archives.

The `clean` circuit and compiler parameters can be inspected here without relying on the Desktop research path. Original files were read only. `SHA256.json` records source identity. This is provenance, not a bit-for-bit reproducible build claim or a safe replacement for the current process boundary. A deliberate rebuild on a different platform requires fresh validation and explicit artifact pin updates.
